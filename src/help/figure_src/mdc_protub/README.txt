MdcProtub help figures
===================

mdc_protub_figs.py draws the figures of ../../MdcProtub.md into ../../images/: MdcProtub_types, _members, _dims, _phi.  It uses
the helpers of ../mdc_bod/datcomfig.py, and the checks of what the page states are in ../mdc_bod/verify.py.  Nothing in
this folder is installed; keep it free of .md files.

    cd src/help/figure_src/mdc_protub
    <build>/venv/bin/python mdc_protub_figs.py            # every figure, or name some (see FIGS at the end)

See ../mdc_bod/README.txt.
