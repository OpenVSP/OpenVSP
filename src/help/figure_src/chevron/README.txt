Body help figures: Chevron
==========================

chevron_figs.py draws the figures of ../../Chevron.md into ../../images/: Chevron_3d, _waveform and _shaping.  It uses
the shared helpers in ../fuselagestack/bodyfig.py, and the checks of what the page states are in
../fuselagestack/verify.py.  Nothing in this folder is installed; keep it free of .md files.

    cd src/help/figure_src/chevron
    <build>/venv/bin/python chevron_figs.py                # every figure, or name some (see FIGS at the end)

See ../fuselagestack/README.txt for the conventions.
